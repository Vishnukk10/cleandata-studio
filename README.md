#  CleanData Studio

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](YOUR_STREAMLIT_APP_LINK_HERE)

An automated Data Quality & Exploration Dashboard built with Python, Streamlit, and Plotly. Upload any CSV file to instantly clean missing values, drop duplicates, detect outliers, and generate interactive visual charts.

---

##  Features

* **Instant Quality Audit:** Get real-time metrics on missing cells, duplicate rows, and column counts.
* **Smart Auto-Cleaning:** Handle missing numerical data using mean, median, or zero substitution, with automatic rounding.
* **Outlier Detection:** Detect statistical anomalies in numerical distributions automatically.
* **Interactive Data Visualization:** Generate customizable Bar, Line, and Scatter plots using Plotly.
* **Export Ready:** Download the cleaned dataset as a CSV file with a single click.

---

##  Tech Stack

* **Language:** Python 3.10+
* **Framework:** Streamlit
* **Data Manipulation:** Pandas
* **Data Visualization:** Plotly
